# Package index

## Fixed-sample designs

Rejection region, exact power and sample size of a two-arm trial with a
binary endpoint.

- [`BinaryRR()`](https://gosukehommaex.github.io/bbssr/reference/BinaryRR.md)
  : Rejection Region for Two-Arm Trials with Binary Endpoints
- [`BinaryPower()`](https://gosukehommaex.github.io/bbssr/reference/BinaryPower.md)
  : Power Calculation for Two-Arm Trials with Binary Endpoints
- [`BinarySampleSize()`](https://gosukehommaex.github.io/bbssr/reference/BinarySampleSize.md)
  : Sample Size Calculation for Two-Arm Trials with Binary Endpoints

## Blinded sample size re-estimation

Operating characteristics of a re-estimation design, comparison of
several designs, and the re-estimation from the data of a trial that is
under way.

- [`BinaryPowerBSSR()`](https://gosukehommaex.github.io/bbssr/reference/BinaryPowerBSSR.md)
  : Power of a Blinded Sample Size Re-estimation Design for Binary
  Endpoints
- [`BinaryGridBSSR()`](https://gosukehommaex.github.io/bbssr/reference/BinaryGridBSSR.md)
  : Power and Sample Size of Several Blinded Sample Size Re-estimation
  Designs
- [`BinaryBSSR()`](https://gosukehommaex.github.io/bbssr/reference/BinaryBSSR.md)
  : Sample Size Re-estimation from Observed Blinded Interim Data

## Type I error rate

Type I error rate of a re-estimation design, the adjusted significance
level that controls it, and its decomposition by the interim outcome.

- [`BinaryTypeIErrorBSSR()`](https://gosukehommaex.github.io/bbssr/reference/BinaryTypeIErrorBSSR.md)
  : Type I Error Rate of a Blinded Sample Size Re-estimation Design
- [`BinaryAlphaAdjBSSR()`](https://gosukehommaex.github.io/bbssr/reference/BinaryAlphaAdjBSSR.md)
  : Adjusted Significance Level of a Blinded Sample Size Re-estimation
  Design
- [`BinaryCondRejectBSSR()`](https://gosukehommaex.github.io/bbssr/reference/BinaryCondRejectBSSR.md)
  : Conditional Rejection Probabilities of a Blinded Sample Size
  Re-estimation Design

## Paired binary data

Fixed-design and re-estimation calculations for a matched-pairs design,
such as a cross-over trial.

- [`PairedRR()`](https://gosukehommaex.github.io/bbssr/reference/PairedRR.md)
  : Rejection Region for Paired Binary Data
- [`PairedPower()`](https://gosukehommaex.github.io/bbssr/reference/PairedPower.md)
  : Power for Paired Binary Data
- [`PairedSampleSize()`](https://gosukehommaex.github.io/bbssr/reference/PairedSampleSize.md)
  : Sample Size for Paired Binary Data
- [`PairedPowerBSSR()`](https://gosukehommaex.github.io/bbssr/reference/PairedPowerBSSR.md)
  : Power of Blinded Sample Size Re-Estimation for Paired Binary Data
- [`PairedBSSR()`](https://gosukehommaex.github.io/bbssr/reference/PairedBSSR.md)
  : Blinded Sample Size Re-Estimation from Paired Interim Data
- [`PairedTypeIErrorBSSR()`](https://gosukehommaex.github.io/bbssr/reference/PairedTypeIErrorBSSR.md)
  : Type I Error Rate of Blinded Sample Size Re-Estimation for Paired
  Binary Data
- [`PairedAlphaAdjBSSR()`](https://gosukehommaex.github.io/bbssr/reference/PairedAlphaAdjBSSR.md)
  : Adjusted Significance Level of Blinded Sample Size Re-Estimation for
  Paired Binary Data

## Stratified designs

Fixed-design and re-estimation calculations for a trial stratified into
two or more strata.

- [`StratRR()`](https://gosukehommaex.github.io/bbssr/reference/StratRR.md)
  : Rejection Region of a Stratified Test
- [`StratPower()`](https://gosukehommaex.github.io/bbssr/reference/StratPower.md)
  : Exact Power of a Stratified Test
- [`StratSampleSize()`](https://gosukehommaex.github.io/bbssr/reference/StratSampleSize.md)
  : Sample Size of a Stratified Test
- [`StratPowerBSSR()`](https://gosukehommaex.github.io/bbssr/reference/StratPowerBSSR.md)
  : Power of Blinded Sample Size Re-Estimation for a Stratified Design
- [`StratBSSR()`](https://gosukehommaex.github.io/bbssr/reference/StratBSSR.md)
  : Blinded Sample Size Re-Estimation for a Stratified Trial
- [`StratTypeIErrorBSSR()`](https://gosukehommaex.github.io/bbssr/reference/StratTypeIErrorBSSR.md)
  : Type I Error Rate of Blinded Sample Size Re-Estimation for a
  Stratified Design
- [`StratAlphaAdjBSSR()`](https://gosukehommaex.github.io/bbssr/reference/StratAlphaAdjBSSR.md)
  : Adjusted Significance Level of Blinded Sample Size Re-Estimation for
  a Stratified Design
- [`StratCondRejectBSSR()`](https://gosukehommaex.github.io/bbssr/reference/StratCondRejectBSSR.md)
  : Conditional Rejection Probabilities of Blinded Sample Size
  Re-Estimation for a Stratified Design
